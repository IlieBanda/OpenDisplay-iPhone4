# OpenDisplay 4

Экспериментальный нативный ресивер OpenDisplay для **iPhone 4 с jailbreak и iOS 6.x**.
Objective-C, UIKit, старый VideoToolbox и OpenGL ES 2. Без Swift, Metal и современных системных API.

На iPhone3,1 / iOS 6.1.3 приложение принимает и отрисовывает **960×640 / 60 FPS**.
Декодированные BGRA-кадры передаются в OpenGL ES 2 через CoreVideo texture cache,
без копирования на CPU и без уменьшения разрешения. В 30-секундном тесте получены
и декодированы все 1800 кадров; установившийся вывод составил 58.7–60.0 FPS.
Это измерения данного устройства: ровно 60 новых кадров каждую секунду не гарантируются.
Статичный рабочий стол может передаваться реже, потому что официальный отправитель
захватывает изменения экрана. Официальный Mac-отправитель менять не нужно.

## Использование

1. Открой **OpenDisplay 4** на iPhone. Ресивер включается автоматически.
2. Подключи телефон кабелем или держи его и Mac в одной локальной сети.
3. Выбери **iPhone 4** в официальном OpenDisplay на Mac.

Экран ожидания **Ready to connect** оформлен в стиле iOS 6. Меню, переключателей
качества и кнопок поверх трансляции нет. После отключения Mac приложение возвращается
к ожиданию и продолжает принимать подключения. После возврата из фона ресивер запускается сам.
Пока приложение открыто, автоматическая блокировка экрана отключена.
При уходе на домашний экран или блокировке приложение нормально завершается.
На iOS 6 это освобождает системный кеш OpenGL перед приостановкой; следующее открытие
автоматически запускает новый ресивер. Работа в фоне не запрашивалась.

Касание управляет мышью, два пальца прокручивают. Как в официальном iOS-клиенте,
нажатие откладывается до отпускания, удержания 120 мс или движения больше 10 точек.
Это отделяет короткий тап от перетаскивания и позволяет отменить нажатие при втором пальце. Звук остаётся на Mac.
Автоматический поворот: 960×640 в альбомной ориентации, 640×960 в портретной.
Ресивер повторно отправляет hello с текущими размерами по живому соединению; sender
перестраивает рабочий стол. Для iPhone 4 в sender выбери размер **Native (1x)**:
macOS может отвергать переключение маленького Retina-дисплея и откатывать ориентацию.
Native использует полный кадр без уменьшения разрешения. Только H.264, цель 60 FPS.
Курсор передаётся по TCP. Очередь ограничена тремя готовыми кадрами.
HEVC и UDP-курсор не реализованы. Битрейт определяет настройка качества официального отправителя.

Иконка использует официальное изображение OpenDisplay со скруглением и стеклянным
бликом в стиле iOS 6. Пользователь подтвердил её отображение после обновления SpringBoard.

## Скачать готовую сборку

[Релизы и IPA](https://github.com/IlieBanda/OpenDisplay-iPhone4/releases/latest).
Для iPhone 4 с jailbreak и iOS 6.x; проверено на iOS 6.1.3.
IPA подписан ad hoc: нужен установщик с поддержкой таких приложений на jailbreak.
Проверенный способ установки — архив `OpenDisplay4-device.tar.gz` через SSH:
скачай архив из релиза в папку `build/`, затем выполни `./tools/device.sh install`.
Для этого способа сборка и SDK не нужны. Сначала запусти USB-туннель, как описано ниже.

## Сборка на Mac

Нужны Xcode Command Line Tools, `ldid`, Python 3 и FFmpeg с libx264.
Старый SDK хранится только локально в `.deps/`:

```sh
./tools/setup-sdk.sh
./tools/test.sh
./tools/build.sh
```

Для своего SDK можно задать `OD_IOS_SDK=/absolute/path/iPhoneOS6.1.sdk`.
Готовые файлы: `build/OpenDisplay4.ipa`, `build/OpenDisplay4-device.tar.gz`.
Сборка armv7 подписана ad hoc для jailbreak; это не App Store/TestFlight-сборка.

Новый Apple linker теряет Thumb-биты в точке входа и ссылках на Objective-C методы
при работе с этим старым SDK. Поэтому весь код собирается в ARM-режиме (`-marm`).
Это исправление проверено на реальном A4; отсутствие новых dyld fixup chains также обязательно.

## Установка по USB/SSH

На телефоне должен работать OpenSSH. Пароль вводится интерактивно и не сохраняется в исходниках.
В отдельном терминале:

```sh
iproxy 2224:22
```

Затем:

```sh
./tools/device.sh install
./tools/device.sh start
./tools/device.sh logs
```

Приложение устанавливается в `/Applications/OpenDisplay4.app` и регистрируется на домашнем экране.
Скрипт обновляет только это приложение. `OD_SSH_PORT` меняет локальный порт SSH-туннеля.

## Проверка сетевого потока

```sh
iproxy 9004:9000
python3 tools/test_sender.py 127.0.0.1 --port 9004 --seconds 30
python3 tools/test_sender.py 127.0.0.1 --port 9004 --seconds 30 --profile high
```

Для Wi-Fi вместо 127.0.0.1 укажи адрес телефона, без `--port`.
Другой отправитель не должен одновременно подключаться: по протоколу новое соединение заменяет старое.
Для изолированных USB-тестов приложение можно запустить с аргументами
`-ListenPort 9001`, а `iproxy` направить на 9001.
Аргументы запуска не меняют сохранённые настройки обычного запуска.

## Диагностика

Лог: `/var/mobile/Documents/OpenDisplay-iPhone4.log` при установленном через SSH приложении.
Хранятся текущий лог до 1 MiB и предыдущий. Записываются символы декодера, SPS, ошибки,
полученные/декодированные кадры, частота и время последнего декодирования.
Время decode не является сквозной задержкой и не является медианой.
Свойство VideoToolbox, подтверждающее аппаратное ускорение, недоступно на этой iOS;
приложение не выдаёт успешное создание декодера за подтверждение этого свойства.

Подробности: [заметки об исследовании](IPHONE4-NOTES.md), [проверки устройства](docs/DEVICE-TESTS.md).
